# Andrea's Personal Site

Two pages: `index.html` (about me) and `petsitting.html` (pet sitting side hustle), plus one shared `style.css`.

## Adding your photos

Every image lives in `images/` and currently contains a labeled placeholder. Just **overwrite the file with your real photo, keeping the same filename** — no code changes needed:

| File | Where it appears |
|---|---|
| `strip-1.jpg` … `strip-6.jpg` | Scrolling polaroid strip at the top (portrait photos work best) |
| `01-cyprus.jpg` … `10-future.jpg` | One photo per numbered chapter |
| `professor.jpg` | The inspiration credit in the footer |
| `pets-hero.jpg` | Pet sitting page (you with a furry client) |

Tip: keep photos under ~500 KB each so the page loads fast (export at ~1200px wide).

## Things to fill in

- `index.html` footer: replace `[Professor's name]` with his actual name.
- `petsitting.html` contact section: replace `your-email@example.com`, the WhatsApp number (`357XXXXXXXX`), and your PetBacker profile URL.

## Publishing on GitHub Pages

1. Create a new **public** repo named exactly `yourusername.github.io` (this gives you the cleanest URL). Otherwise any repo name works too.
2. Upload all files (`index.html`, `petsitting.html`, `style.css`, the `images/` folder, this README).
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute your site is live at `https://yourusername.github.io` (or `https://yourusername.github.io/repo-name`).
5. Paste that link into your LinkedIn bio. Done. 🎉

Any edit you push to the repo goes live automatically within a minute or two.
